# QuickCash

-   QuickCash is a full-stack budgeting application built with Blazor WebAssembly, ASP.NET Core Web API, and SQLite.

-   It allows users to manage income and expense categories, log monthly transactions, and view aggregated financial summaries.

## Features
-   Create and delete categories (Income / Expense)

-   Create and delete transactions

-   Monthly transaction filtering

-   Monthly income / expense totals

-   Net balance calculation

-   Input validation and business rule enforcement

-   EF Core migrations for schema management

-   Clean separation of concerns (Controller → Service → Repository)

## Tech
- Blazor WebAssembly UI
- ASP.NET Core Web API
- Entity Framework Core (SQLite)
